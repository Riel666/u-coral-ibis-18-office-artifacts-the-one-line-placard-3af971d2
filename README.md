## What it does

`main.ts` writes a single line — the one-line museum placard for an ordinary office object treated as an ancient artifact — to `/output/entry.txt`. The program is fully deterministic: no
randomness, no network, no input. It always writes exactly the same line.

> Sticky note, c. 2019. One yellow tablet bearing the command 'CALL STEVE', its urgency undimmed after five thousand years. On loan from the Archive of Forgotten Errands.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
cat /output/entry.txt
```
